# Instagram Carousel — 1080×1350 per slide

> Current direction: all new posts use a white theme (Off-White #F5F3EF), Night #0E0E10 text, and Burnt Orange #E35205 accents. Place the official logo at the top-left. Generate backgrounds without text or logos; add exact assets and variable content with the Python renderer.

> Prompt = `00-brand-core.md` + this block.

```
FORMAT: Instagram carousel, 1080x1350 px each slide, 4–8 slides.
CONSISTENCY: white theme, same margins (80px), same font sizes, official logo top-left on EVERY slide.
SLIDE 1 (cover): big headline + "SWIPE →" small in orange bottom-right.
SLIDES 2–N: one idea per slide. Slide number "02 / 06" top-right in orange.
  Short title + max 3 lines or 3 bullet points.
LAST SLIDE: call to action (join, register, follow) + official logo top-left.
CONTINUITY: an orange line or angled shape that continues from one slide
  edge to the next, so swiping feels connected.
```
