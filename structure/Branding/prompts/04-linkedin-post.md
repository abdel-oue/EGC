# LinkedIn Post — Professional

> Current direction: all new posts use a white theme (Off-White #F5F3EF), Night #0E0E10 text, and Burnt Orange #E35205 accents. Place the official logo at the top-left. Generate backgrounds without text or logos; add exact assets and variable content with the Python renderer.

> Prompt = `00-brand-core.md` + this block. LinkedIn = sponsors, admin, recruiters. Less gamer, more organization.

```
FORMAT: LinkedIn image 1200x1500 (4:5) or 1200x627 (link-style), or PDF carousel 1080x1350.
BACKGROUND: Off-White #F5F3EF (light, corporate). White theme also applies to event recaps.
ACCENT USE: Burnt Orange #E35205 very small — one thin line, one keyword,
  or the logo only. Max ~5–10% of the design.
LAYOUT:
- Top-left: full logo lockup (wordmark), in orange or Night.
- Headline: Space Grotesk Bold, sentence case (NOT all caps), Night #0E0E10.
- Supporting: 1 number or key fact large (e.g. "120 participants").
- Real photo of event/team, clean crop, no heavy filters.
- Bottom: thin orange line + "ESISA Gaming Club · Fès".
FORBIDDEN: memes, emoji spam, gaming slang, neon effects.
```

## Text template
```
[Line 1: result or news — must make people click "voir plus"]

[2–3 short paragraphs: context, what happened, impact]

Merci à [partenaires / staff / @école] pour leur soutien.

[Forward-looking line: prochaine étape / on cherche des partenaires]

#ESISA #Esports #Étudiants #Fès #Événementiel
```

## Post types
- Event recap (numbers + photos)
- Partnership / sponsor announcement (both logos, equal size)
- Team / bureau presentation (portraits, names, roles)
- Season launch (vision + goals)
