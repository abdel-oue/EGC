# Event Poster / Print — A3, A4, screen

> Current direction: all new posts use a white theme (Off-White #F5F3EF), Night #0E0E10 text, and Burnt Orange #E35205 accents. Place the official logo at the top-left. Generate backgrounds without text or logos; add exact assets and variable content with the Python renderer.

> Prompt = `00-brand-core.md` + this block.

```
FORMAT: A3 or A4 portrait poster (print 300 DPI, CMYK) + digital 1080x1350 version.
BACKGROUND: Off-White #F5F3EF for all posters and digital posts; orange/black details only.
LAYOUT:
- Top-left: official logo lockup.
- Big: event name, Space Grotesk Bold uppercase.
- Game/visual: abstract geometric shapes or real photo — NO copyrighted game
  characters or official game art unless authorized.
- Info block: DATE · HEURE · LIEU · PRIX / CASHPRIZE, aligned left, orange labels.
- QR code bottom-right (registration), with "Inscris-toi" above.
- Sponsor logos bottom row, all same height, monochrome black on white.
PRINT RULE: 5mm bleed, no text within 10mm of edge, readable from 3 meters.
```

## Tournament announcement structure
1. Event name
2. Game + format (5v5, solo, BO3...)
3. Date / time / place
4. Prize
5. Registration (QR + deadline)
6. Sponsors
