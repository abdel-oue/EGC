# Other Formats — Profiles, Discord, Video, Results

> Current direction: all new posts use a white theme (Off-White #F5F3EF), Night #0E0E10 text, and Burnt Orange #E35205 accents. Place the official logo at the top-left. Generate backgrounds without text or logos; add exact assets and variable content with the Python renderer.

> Always start with `00-brand-core.md`.

## Profile pictures
- Instagram / Discord / LinkedIn avatar: **icon only**, orange on Off-White #F5F3EF, centered, 20% padding.
- Test at 32px. If unreadable, use the icon without the small details.

## Quick checklist before publishing
- [ ] Orange used only on 1–2 elements?
- [ ] Logo from official files, not redrawn?
- [ ] Max 2 fonts, max 3 text sizes?
- [ ] Readable in 2 seconds on phone?
- [ ] No text in story UI zones?
- [ ] Spelling checked (French accents!)?
